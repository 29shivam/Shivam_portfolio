# 💻 Shivam Singh – Developer Portfolio

Welcome to my personal portfolio! This site showcases my projects, skills, experience, and how to get in touch with me. Built using modern web technologies like **Next.js**, **Framer Motion**, **Three.js**, and **EmailJS**, it's designed to be interactive, responsive, and recruiter-friendly.

---

## 🚀 Live Demo

🌐 [https://shivam-portfolio.vercel.app](https://shivam-portfolio.vercel.app)

---

## 🧰 Tech Stack

- **Framework**: [Next.js](https://nextjs.org/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **3D Graphics**: [React Three Fiber](https://docs.pmnd.rs/react-three-fiber), [Drei](https://github.com/pmndrs/drei)
- **Contact Email Integration**: [EmailJS](https://www.emailjs.com/)
- **Styling**: Tailwind CSS
- **Deployment**: [Vercel](https://vercel.com)

---

## 📦 Features

- 👨‍💼 About Me & Skills section with animated tech stack
- 💼 Projects section with live demo + GitHub links
- 📄 Resume download or view link
- 🌎 Interactive 3D Earth Canvas
- ✉️ Fully functional contact form powered by EmailJS
- 🌙 Dark mode compatible
- ⚡ Smooth animations and transitions with Framer Motion

## 🛠️ Local Development

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/shivam-portfolio.git
cd shivam-portfolio

3. Create .env.local File
Add the following environment variables:

NEXT_PUBLIC_EMAILJS_SERVICE_ID=your_service_id
NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=your_template_id
NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=your_public_key

npm run dev
